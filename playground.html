Fracture-Bench

About the datasets & playground

Pick a test case · Compare surrogates · Inspect FEM error · Try your own case

Choose a dataset and one of its held-out test cases, then compare the trained surrogates side by side with the finite-element (FEM) result and a pixel-wise error map. Or set up a new case of your own: the surrogates then run live in your browser.

Phase-field models are the method of choice for simulating fracture (crack nucleation, propagation, branching and coalescence) within a single variational framework. But each quasi-static simulation is expensive, which makes ensemble workflows such as uncertainty quantification, Bayesian inference and design optimization intractable.

Fracture-Bench is a benchmark suite that evaluates machine-learning surrogates which replace the finite-element solve with a single network forward pass. Five architectures (UNet, FNO, DeepONet, Latent DeepONet and a conditional denoising diffusion model) are trained on identical data splits and scored with common test metrics across two high-fidelity datasets that differ in phase-field formulation, material heterogeneity and prediction task.

Evaluation spans accuracy, computational efficiency and generalization to load steps withheld during training. The headline result: no single architecture dominates, and prediction difficulty grows with material heterogeneity and crack-path sensitivity. The datasets, evaluation protocols and model code are released openly.

Dataset 1 : Perforated plate of hyperelastic material

  • Formulation: phase-field fracture, AT2 model
  • Domain: Ω = [−1.1, 1.1]² square plate, central hole r = 0.5, eight notches · grid 128 × 128
  • Loading: boundary displacement u = ε̄n f(s) x on ∂Ω, with f a periodic Gaussian random field · 44 load steps
  • Operator: 𝒢 : u(x,0) ↦ d(x,t), t ∈ {t1,…,t44}
  • Phase field: vector d(x,t) ∈ ℝ² (after Hakimzadeh et al.); the scalar damage ‖d‖ ∈ [0,1] is shown
  • Size: 1,000 simulations · train / test = 900 / 100
  • Download the full dataset from the JHU Data Archive.
  • Get the simulation and data-generation code from the GitHub repository.

Dataset 2 : Heterogeneous plate with two inclusions

  • Formulation: phase-field fracture, PF-CZM model
  • Domain: 4 mm × 8 mm plate · two circular inclusions · grid 128 × 256
  • Material: modulus field E(x); each inclusion stiffer (E = 10 Em) or softer (E = 0.1 Em) than the matrix
  • Loading: Mode-I tension, 31 load steps
  • Operator: 𝒢 : (d(x,0), E(x)) ↦ d(x,tf)
  • Phase field: scalar d ∈ [0,1] (0 = intact, 1 = fully cracked); only the final step tf is predicted
  • Size: 4,000 simulations (4 inclusion configurations) · train / test = 3,600 / 400
  • Download the full dataset from the JHU Data Archive.
  • Get the adaptive-mesh simulation and data-generation code from the GitHub repository.

Crack growth in a perforated hyperelastic plate (AT2) under a Gaussian-random-field boundary displacement.
  • Test case: one of 10 held-out FEM simulations that the models never saw in training.
  • Surrogates: compare FNO, DeepONet and Latent DeepONet at 11, 22 or 44 load steps.
  • Output: the damage ‖d(x,t)‖ at each load step next to FEM, and the error |prediction − FEM| below. Press Play to watch the crack grow.
  • New load: switch the input to New load (live) to draw your own boundary load. DeepONet and Latent DeepONet then predict the crack growth in your browser.
Input

Boundary load

A new load from the Gaussian random field of the FEM data generator:
f(s) = μ + Σn λn [ξn cos nφ + ηn sin nφ], λn = √2 σ ((2πn)² + τ²)−γ/2

The training data used γ = 4, τ = 5, σ = 625 and μ = 1. Other values give loads unlike any the model was trained on.
